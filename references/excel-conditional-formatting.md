# Excel 条件格式与单元格图形

用途：将**已给定数据**制作成可读、可维护的表格。这里只处理显示规则和必要算术，不做VOC分类、策略评价或完整报告写作。与 [管理层表格](management-tables.md) 配合使用。

## 先选择编码，再实现

| 读者需要比较 | 首选方法 | 配置重点 |
|---|---|---|
| 一列规模的大小/排名 | 原生数据条＋原值 | 非负量通常以0为下界；比较范围共用上界 |
| 相对基准的正负差 | 零轴两侧数据条＋带符号数值 | 保留真实负号；基准、单位明确 |
| 二维大小分布 | 顺序色阶热力表＋格内数字 | 同一比较问题使用一致色阶与单位 |
| 偏离目标的程度 | 有明确中心的发散色阶 | 中心必须是0差额、100%达成率或已给目标 |
| 是否达到既定标准 | 图标集/公式规则 | 使用业务阈值，数字、百分比阈值和百分位不可混用 |
| 一行跨期轨迹 | 原生折线/柱形迷你图 | 与原值相邻，注明行间是否同尺度 |
| 轻量文字条 | REPT | 只是显示近似长度，保留原数值；不替代原生图表 |

Excel提供数据条、色阶和图标集规则，可对指定范围管理；图标按阈值区间分类。[Microsoft：条件格式](https://support.microsoft.com/en-gb/excel/use-conditional-formatting-to-highlight-information-in-excel)

## 数据条：让表格具备长度比较

- 优先实色、低饱和、可读的数字，不给所有列同时加条。必要时分成“条形列＋数值列”，且两者链接同一原值。
- 多组/多期若需要横向比较，显式使用同一上下界；按每列自身最大值拉满只能比较各列内部排名，必须说明。
- 零值无长度，缺失不画条；不要把空单元格、公式空字符串或错误值全部改成0。
- 合计行与明细不是同层级，通常将合计排除在数据条标尺之外，单独显示合计；否则合计可能压扁所有明细。
- 负差以0为中心延伸；箭头朝下仅表示数值下降，是否为好消息由指标定义决定。
- 实际/计划蝴蝶表可让左列朝左、右列朝右，**左右保持同尺度**，旁列显示真实差额和达成率。左边条形方向是版式，不把实际金额改为业务负值。原生工具不支持方向时用两列并列条或原生图表，不伪造能力。

## 色阶与图标：一眼看出重点，但不改变数值

- 同指标跨城市/期别用统一色阶；不同量纲分开。话题/类别矩阵如果逐行归一，明确“每行独立色阶，仅行内比较”，不能用颜色比较跨行绝对大小。
- 份额可用固定0–100%或明确的有效范围；正负变动围绕0，达成率可围绕100%。不要把样本中位数无说明地当成目标。
- 图标阈值若表示10%，原数值是0.10；“数值=0.10”“范围位置百分比=10”“第10百分位”含义不同。阈值旁保留定义。
- 图标集只做方向或状态，不再给同一格叠加无关色阶和数据条。箭头、加减号和数字配合，不能只依赖红绿。
- 不同主题/图标方案已经确定时沿用；不要因Excel默认是绿上红下就改变既有业务语义。

## 公式条件格式：把规则写在正确位置

以下是布局示例，不是固定业务阈值。B列为前期、C列为本期、E列为已算好的变化率；正式使用前替换为真实列。

| 用途 | 示例公式/适用范围 | 解释 |
|---|---|---|
| 变化率，仅正基期可算 | `=IF(AND(ISNUMBER(B2),ISNUMBER(C2),B2>0),C2/B2-1,"")` | 零/负基期或缺失另列状态，不用空结果冒充0% |
| 本期大于前期，高亮本期单元格 | `=AND(ISNUMBER($B2),ISNUMBER($C2),$C2>$B2)`；应用于`C2:C20` | 锁列不锁行，每一行比较自己的两期 |
| 变化超过已给阈值 | `=IFERROR(AND(ISNUMBER($E2),ISNUMBER($K$1),$E2>$K$1),FALSE)`；应用于`E2:E20` | K1是可见且已确认的参数；错误不触发颜色 |
| 明确显示缺少前期 | `=NOT(ISNUMBER($B2))`；应用于`B2:B20` | 只标本任务定义的非数字，勿扩大为全表错误审计 |

公式以应用范围左上格为基准；`$E2`随行变，`$E$2`固定一格。复制规则后复查“应用于”范围与引用偏移，不能把所有行误指向第一行。Excel规则管理器按优先级处理冲突；`Stop If True`需要按规则类型检查，不能直接给数据条/色阶/图标集设置该开关。[Microsoft：规则顺序与公式引用](https://support.microsoft.com/en-gb/excel/use-conditional-formatting-to-highlight-information-in-excel)

默认不要覆盖整张工作表或添加上千个逐格重复规则。对同含义连续范围建立规则；已有文件只改任务涉及的范围，保留其他格式。

## 迷你图：在表中表达轨迹

- 将迷你图放在同一行原数据旁，保持时间顺序；一般选折线看趋势、柱形看期别量、盈亏图看正负状态。盈亏图不表达幅度。
- 行间需要比较量级时设置共同的最小/最大值；仅看各行形状可独立缩放，但标“各行独立尺度，仅看走势”。
- 缺期保持空缺或断点，不默认填0；注意真实空单元格与公式`""`在目标工具里的表现，实际检查导出结果。
- 首/末点或最高/最低点按问题择一强调，避免全部加彩色标记。有正负数时显示零轴。
- 明确数据区域与放置区域的对应关系，新增行后检查是否覆盖新数据，不能只复制静态截图。

Excel原生迷你图支持折线、柱形及盈亏类型，设置轴、标记及上下界。[Microsoft：迷你图类型](https://support.microsoft.com/en-us/excel/get-started/use-sparklines-to-show-data-trends)、[Microsoft：迷你图轴设置](https://support.microsoft.com/en-gb/excel/analyze-trends-in-data-using-sparklines)

## REPT、气泡与 mini 饼：采用结构，不照搬所有编码

非负B列的文字条示例，约定最长40字符，原数字保留在相邻列：

```excel
=IF(AND(ISNUMBER(B2),B2>=0,MAX($B$2:$B$20)>0),REPT("▌",ROUND(40*B2/MAX($B$2:$B$20),0)),"")
```

- REPT是重复字符而非连续长度，字体/列宽会影响观感；很小值可能因取整显示为空条，不能误判为零。全0列不除以0。字符缺失时更换可显示字符或用原生数据条，不偷偷换掉整表字体。
- 文本条只是辅助，不能据长度读出比原数据更精确的数。REPT重复次数有截断行为，结果长度也有限制。[Microsoft：REPT函数](https://support.microsoft.com/en-us/excel/functions/rept-function)
- 气泡以**面积**对应非负量，自绘时半径与数值平方根成正比；负增长不直接做负面积，可以另用正负颜色＋绝对值面积并清楚标注，精确比较优先条形。
- mini饼只用于有明确整体的非负部分占比（部分＋其余＝100%）。普通增长率不是构成比，可能为负或超过100%，不用mini饼表达。
- Harvey球用于明确量表的等级/完成程度，须有图例；不能把1/4格的评分外观写成精确25%原始调查占比。

## 原生实现与验收

1. 若交付XLSX，用当前可用的电子表格工具创建**真实条件格式规则/原生迷你图**，具体API查该工具文档。环境提供Spreadsheets技能时遵循其创作与导出流程；这里不规定另一套冲突的库。
2. `tc_render.py` 不直接生成XLSX条件格式。HTML中的CSS色阶/SVG迷你图、PPT形状和PNG是各自载体的呈现，不能声称为会随Excel数据变化的原生规则。
3. 若工具不能写某种原生功能，选择支持的替代并明确能力；不要手工涂色后声称已经写入条件格式，也不要发明未支持的API。
4. 对实际创建的文件核对规则类型、范围、阈值、优先级、图标方向、格式与数值；在测试副本改变一个大值、小值、负值和缺失值，确认显示符合规则。恢复测试值，不改动真实源数据。
5. 重算公式后检查最终显示值和报错；导出/重开后检查规则是否仍在。对实际交付尺寸查看全部表格，不能只检查文件生成成功。

以上菜单和功能依据Microsoft官方说明核对；不同平台或工具不支持的能力不强行宣称具备。参考图只用于选择表达方式，不将其示例数字带入用户结果。
