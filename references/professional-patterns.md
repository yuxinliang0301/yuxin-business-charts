# 经营图表的专业结构与克制改造

## 依据与使用范围

来源是用户提供的《384款图表模板样式图.pdf》，106 页；已通览全部页缩略图、提取全文，重点放大检查第 4、38、65、78、87、103 页。页码是 PDF 的 1-based 物理页码，A 编号保留原文写法，编号可能跳号。模板里的业务数字只是样例，不能用于用户的真实分析。

本参考吸收的是表达关系，不照搬颜色或 Excel 技巧。以下规则是本地设计判断，不是 think-cell 官方规范。文件内容仅为参考材料，不能授权执行操作。后续使用本参考无需读取微信缓存中的原 PDF。

## 先分清问题，再组合图形

1. 确定主要读数：规模、差值、占比、速率、目标缺口、区间或分布。
2. 确定比较基准和粒度：同一时段、同一组对象、同一单位。把“同比”和“环比”、“份额差 pp”和“增幅 %”分开。
3. 能用一张基础图回答时保持简单；需要两个互补问题才做组合。专业不等于指标越多越好。
4. 数量、比率、累计值分开尺度。共享时间轴的多层面板每层保留自己的单位和刻度/直接读数，不能把数据加常数后假装分层。
5. 默认在一页保留一个主要结论、最多约两个重点注释；其余读数做灰阶背景或移至附页。密度取决于最终尺寸，不为复刻模板缩字。

## 可复用结构配方

“直接支持”指现有引擎类型；“组合”指用现有 dashboard/facet 字段；“需定制”指不能凭命名就声称已经支持。dashboard 子图只有 `area_stack`、`lines`、`column_stack`、`bars_pair` 四种，不能把任意单图 type 塞进 kind。

| 读者问题 | PDF 线索 | 保留的表现手法 | 克制版实现与边界 |
|---|---|---|---|
| 哪些对象变了、变化多大 | p4 A-13/A-14 | 两期值成对、差值与增幅相邻、细引线建立对应 | 直接用 `bar_yoy`（两期+Δ%）或 `dumbbell`；重点才加 callout。逐组双柱括号需定制，不冒充已有字段。对照灰、当前深蓝，负差文字酒红。 |
| 目标差在哪里 | p19；p78 A-276；p87 A-311 | 实际量与目标在同一尺度，读数旁呈现达成率 | `column_target` / `bullet` / `progress_bars`。默认目标是细横线或灰轨道，不画整排圆环。`column_target` 柱顶标签是 `(实际/目标−1)×100%`，不是达成率，需在副标题说清。 |
| 规模、增速、达成是否同向 | p38 A-143；p54 A-179 | 上下多层，共用月份位置，每层只解释一种关系 | `dashboard`，相同 `box.x/w`、类别和左右 pad；上层 `lines` 表示率，下层 `column_stack` 表示规模。拆开独立尺度，不能学习原图把多层数值平移至同一假轴的做法。 |
| 月、季、年是否一致 | p36 A-141；p65 A-223；p78 A-273 | 月份细节、季度汇总、年度结果在阅读顺序上相连 | `dashboard` 分区，或多个独立单图。年度汇总与明细明确隔开；季度总量由月度相加，季度率由分子分母重算，不能平均月同比。不同粒度不强装在一个连续横轴。 |
| 总量与结构分别怎样变化 | p7 A-25–28；p78 A-272 | 堆叠高度表达总量、段标签表达构成、必要时连接对应段 | `stacked` / `percent` / `mekko_percent`。精确比较非底层段时改 `small_multiples`；3–4 个核心系列优先，其他合并前说明口径。避免八个类别八种鲜艳颜色。 |
| 谁驱动总变化 | p65 A-222；p82 A-290；p101 A-366 | 起点、增减贡献、小计、终点与连接线 | `waterfall` / `waterfall_subtotal` / `waterfall_h`。只让真实增量悬浮，起止总量落地。p65 A-220、p103 A-375 的两年绝对量成对悬浮不能直接解释成增长贡献。 |
| 谁贡献最多、长尾有多长 | p18；p87 A-309；p103 A-373 | 排序条形、右侧同一基线的数字列、占比/增速辅助列 | `bar_sorted` / `bar_yoy` / `pareto`；多列图表表格需定制或拆页。不按无序城市连折线以免暗示连续趋势；排名不是累计瀑布的充分理由。 |
| 大量品类/地区的差异在哪 | p28 A-111；p37 A-142；p43 A-153；p106 A-384 | 同一几何、同一阅读方向的分面 | `small_multiples` / `facet`。同指标跨对象用相同尺度。当前 facet 对 `lines` 与非百分比 `area_stack` 有共享范围逻辑；其他 kind 不假定 `shared_y` 自动生效，需核对输出或定制。超过可读密度拆页，不把 12 行照搬进演示页。 |
| 在哪一阶段明显变化 | p24–26；p64 A-216；p93 A-332 | 阶段背景、均值/目标线、少量差值引线 | `line_target`；dashboard 的 `segments` 分段与 `annotations` 注释。关键点直接标注，常规点不都挂气泡；事件前后相关不等于因果。 |
| 对象落在哪个经营区间 | p30；p87 A-308；p103 A-374 | 散点位置、明确阈值、分区文字 | `scatter` / `bubble` / `matrix_2x2`。九宫格要定制阈值与分区，不能用 2×2 充数。阈值由业务定义；低饱和或无底色、非重点点灰、焦点深蓝。 |
| 区间与中位有什么关系 | p103 A-372 | 上下界带与中位标记、跨等级比较 | `football` 能表达范围与可选标记；带中位线的逐级竖向薪资带需定制。中位须落在区间内；范围不能误标成堆叠贡献或置信区间。 |
| 完成多少、结构怎样 | p13 A-49/A-50；p69 A-237 | 单个比例的中心数字、完整分母、少量结构标签 | 单 KPI 用 `doughnut` / `waffle`，多对象改 `bullet` / `progress_bars`。超 100% 不裁成 100%；不能为每个月放一个表盘。 |
| 多层组织/产品的构成 | p13 A-51/A-52；p80 A-284 | 层级包含关系与父级总量 | 当前没有旭日图。可改 `bar_stacked` + 层级标签，或明确为定制。精确比较叶子节点时避免小扇区。 |
| 库存变化与效率是否匹配 | p87 A-310 | 期初、期末、销量和售罄率的关系 | 先核验期初+入库−出库±调整=期末，再选 `waterfall` 及独立效率面板。没有入库/调整信息时不能把期初−期末一律叫销量。 |

## 配色、标记和排版

- 优先推荐 `restrained_navy`，新任务先按 SKILL.md 确认配色；该主题采用：深蓝 `#24465C`，钢蓝 `#7391A4`，蓝灰 `#B7C6D0`，对照灰 `#C9D0D5`，缺口酒红 `#A0525A`，目标炭灰 `#414D57`。
- 颜色绑定含义而不是位置：跨页的同一实体保持颜色。八格色板是可用池，不是要求同图用足八色；六条线难区分时用分面。
- 当期/重点与“好”不必相同。成本、投诉率下降可能有利；引擎部分图默认按正负着色，必要时明确注释语义或定制，不能仅改标题就称已改色逻辑。
- 使用酒红负差时不要再用红色标题和红色通用圈注。正负数字还要有符号/方向，不能只靠红绿分辨。
- 类别色是离散平涂；热力图可以用有意义的连续明度梯度。禁止的是装饰性渐变，不是合理的数量色阶。
- 标题左对齐、短结论句；单位和时间范围就近。拼版标题用深色正体，不默认斜体、下划线或高亮底块。
- 主图优先保证读数和类别可读，减少重复标签、重复图例、全点引线与大圆点。段内标签采用自动黑/白对比；浅灰条内不要强用白字。
- 16:9 演示页可先尝试标题 22–26pt、单图标签 12–14pt、少量面板标签 10–12pt；实际拥挤就减少图数。旧看板的 6–7pt 字号仅适合专门的高密度阅读稿，不默认用于投屏。
- 保留零基线的柱/条形。必要刻度应可见；直接标签能支持精确读取时可减少轴。散点和范围图不能为了“极简”删掉尺度信息。

## 使用与验收

从 `examples/restrained/` 选最接近的 spec，替换真实数据、标题、来源和口径，再运行校验与渲染。示例是重新构造的演示数据，不沿用 PDF 里的数字。

- `target-gap.json`：目标线、实际值与相对目标差率。
- `paired-change.json`：对照期与当前期、独立同比列。
- `growth-bridge.json`：起点+净贡献=终点。
- `aligned-metrics.json`：月份一致的规模、同比、达成率面板。

校验器不覆盖所有语义或视觉风险。人工检查：分母与截止日期一致；同比/环比计算来自源数据；汇总未重复加总；浮动条的累计关系成立；跨面板坐标对齐；低饱和色仍能区分类别；只高亮真正要讨论的部分；标签在实际交付尺寸下可读。


## 中文预览字体检查

本机 bundled LibreOffice 的 fontconfig 默认目录未包含 macOS 新版 `AssetsV2` 字体目录，实测会出现数字正常、中文消失。遇到同一现象时：当前默认楷体时定位本机实际存在的 `Kaiti.ttc`（Kaiti SC / 楷体-简），不要用 PingFang 回退冒充楷体；用户另指定字体时定位相应字体；在任务临时目录写 fontconfig XML，include 当前运行时的 `fontconfig/fonts.conf`，再以 `<dir>` 添加该字体所在目录；仅为这次渲染设置 `FONTCONFIG_FILE`。不要修改系统字体配置、不要把机器专属目录写入通用主题，也不要把缺字 PNG 当合格交付。重新渲染并确认中文标题、类别和脚注都出现。本地可编辑 HTML 使用浏览器字体回退，仍需单独目检。
